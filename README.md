# Calculadora de Beta para acciones
Herramienta simple para calcular el Beta (β) de cualquier acción contra un benchmark, usando datos reales de Yahoo Finance. La hice mientras cursaba Finanzas para entender mejor el concepto y poder aplicarlo sin depender de Excel. Usa regresión lineal y genera un análisis automático con IA. Hecha en Python — funciona en Google Colab sin instalar nada.
